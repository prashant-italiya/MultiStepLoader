# Contributing to MultiStepLoader

Thank you for considering contributing to MultiStepLoader! This document outlines the process for contributing to this project.

## Code of Conduct

By participating in this project, you agree to maintain a respectful and inclusive environment for everyone.

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please open an issue with the following information:
- A clear, descriptive title
- Steps to reproduce the bug
- Expected behavior
- Actual behavior
- Screenshots (if applicable)
- Browser information and operating system

### Suggesting Enhancements

If you have an idea for an enhancement, please open an issue with:
- A clear, descriptive title
- A detailed description of the proposed enhancement
- Any potential implementation options you might have in mind

### Pull Requests

1. Fork the repository
2. Create a branch with a descriptive name:
   ```
   git checkout -b feature/your-feature-name
   ```
3. Make your changes
4. Test your changes
5. Commit your changes with a descriptive message:
   ```
   git commit -m "Add feature: your feature description"
   ```
6. Push to your fork:
   ```
   git push origin feature/your-feature-name
   ```
7. Create a pull request

## Styleguides

### Git Commit Messages

- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less
- Reference issues and pull requests liberally after the first line

### JavaScript Styleguide

- Use 2 spaces for indentation
- Use semicolons
- Prefer const over let, and let over var
- Use camelCase for variables and functions
- Use PascalCase for classes
- Add comments for complex code segments

### CSS Styleguide

- Use 2 spaces for indentation
- Consider using a consistent naming convention (BEM, SMACSS, etc.)
- Group related properties together
- Add comments for complex styling decisions

## Development Setup

1. Clone your fork of the repository
2. Open `loader.html` in your browser to test changes

Thank you for your contributions!
